# 复制订单号

## 这次要做什么

继续使用[第 6 步生成的订单页面](/tutorial/first-page)。订单号太长，手动选中容易漏字符；这次给它加一个复制按钮。如果已有该功能，直接按文末步骤验证。

## 复制这段提示词 {#implementation}

在刚才生成页面的 AI 对话中发送：

```text:no-line-numbers
在刚才的订单管理页面中，给每条订单的订单号旁增加复制按钮。
点击后复制完整订单号，并显示成功提示；复制失败时提示重试。
沿用项目现有组件和工具，只修改相关代码，完成后运行相关检查。
```

## 操作后应看到什么

1. 刷新订单页面，找到一条订单，点击订单号旁的复制按钮，应出现成功提示。
2. 粘贴到一个空白输入框，内容应与这条订单的完整订单号一致，没有多余空格或省略号。
3. 换一条订单重复操作，粘贴内容应随之改变。

这三个操作通过，就完成了这次小改动。接着练习[一键查看失败订单](/tutorial/query-summary)。
