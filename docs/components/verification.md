## 已知源码边界

1. Vue 2 SearchForm 的 type 20 / selectDate 在本次快照中缺少容器 CHECKS 映射，直接放入 items 会报错。日期示例独立运行原始 SelectDateField，并明确说明原因；其他日期和级联字段正常通过容器展示。完整表单接入前应修复来源仓库后显式同步。
2. Vue 2 createSelectOptions 使用 propName/optionsArr，formRender 使用 itemType，与新 SearchForm 不直接兼容；文档和示例分别展示。Vue 2 tableRender 会生成 render，自定义显示使用 render，不能照搬现代栈的 formatter 优先规则。
3. 现有 Vue 2 与 Element UI 间接依赖有上游维护状态提示；Ant Design 5.27.6 对快照使用的 destroyOnClose 给出弃用提示。保留来源源码，不将这些提示伪装成已修复。
