# 把问题说清楚，让 AI 修复

## 这次要做什么

在订单页面点击“只看支付失败”，再点击重置，看看筛选框和列表是否都恢复了。如果重置后仍只显示失败订单，就用下面的方式反馈。

**只有实际遇到问题时才发送修复提示。** 如果重置正常，可用相同结构描述你遇到的其他问题；没有问题就直接进入[检查与交付](/tutorial/review-and-deliver)。

## 复制这段提示词

下面是一份问题描述示例，发送前按你实际观察到的结果修改：

```text:no-line-numbers
订单管理页面重置后，列表没有恢复。
操作：点击“只看支付失败”，再点击重置。
实际：筛选框已恢复初始值，但列表仍只有失败订单。
预期：筛选和列表一起恢复初始条件，页码回到 1。
请定位原因，只修复相关代码，运行相关检查，并说明如何验证。
```

## 操作后应看到什么

1. 刷新页面，记下初始支付状态和列表中有哪些订单状态。
2. 再点“只看支付失败”，然后点重置；筛选与列表应恢复到初始条件，页码为 1。
3. 再选择另一个支付状态查询，确认普通筛选仍然有效。

若问题仍在，把这次操作与结果继续发给 AI；有报错时附上错误原文。确认修复后，进入[检查页面，整理交付说明](/tutorial/review-and-deliver)。
