# 给 AI 一张图，按现有规则生成页面

<p class="lead">把下面的订单管理参考图与提示词一起发送给 AI，让它在当前项目中完成页面。</p>

## 1. 保存并附上参考图

<p><a :href="withBase('/images/order-management-reference.png')" download="order-management-reference.png">下载订单管理参考图</a>，或点击图片查看原图。将图片拖入当前项目的 AI 对话，再粘贴下一节的提示词。</p>

图片提供布局和可见字段，接口参数、业务码值与权限仍以项目源码和已确认的契约为准。

| 区域 | 参考图中的内容 |
| --- | --- |
| 筛选区 | 日期范围、支付时间范围、渠道来源、订单类型、剧集 / 剧集 ID、支付状态、国家名称、订单 / 用户搜索 |
| 操作区 | 搜索、重置、导出 |
| 统计区 | 订单数、成功数、GMV（成交总额）、成功率 |
| 表格区 | 序号、订单编号、用户 ID、用户邮箱、下单时间、付款时间、订单类型、支付金额、订单详情、支付状态、失败原因、用户国家、渠道来源、详情入口 |
| 分页区 | 总条数、页码、上一页 / 下一页、跳页、每页条数 |

## 2. 复制这段页面生成提示词 {#implementation}

```text
请在当前项目中，根据我附上的订单管理截图，实现对应的订单管理页面。

先遵循项目现有规则：
- 读取当前项目的协作约定，以及 .cursor/rules/ai-code.mdc；
  按任务需要读取 .cursor/skills/ 中已安装的相关 AI Code 技能。
- 如果存在 .ai-code/profile.md，读取与本页面相关的已核实条目，
  据此找到推荐组件、组合式函数、目录约定和参考页。
  未填写项或“待人工确认”不能当成事实。
- 如果未生成 profile，从当前项目的相邻页面和源码确定复用入口。
- 核对相关组件的参数、事件和实际调用，复用已有布局、搜索、表格、
  分页、弹窗、请求封装、字典和主题样式；目录与命名沿用当前项目。

页面要求：
1. 还原截图的整体层次：顶部筛选与操作区，四个统计卡片，下方表格与分页。
   颜色、间距、圆角和信息密度尽量接近参考图，同时遵循项目主题。
2. 筛选包含日期范围、支付时间范围、渠道来源、订单类型、剧集 / 剧集 ID、
   支付状态、国家和订单 / 用户搜索，提供搜索、重置、导出按钮。
3. 统计展示订单数、成功数、GMV（成交总额）和成功率；
   表格包含截图中的订单、用户、时间、金额、状态、国家、渠道和详情入口。
4. 查询提交后更新列表；重新查询回到第一页；重置恢复全部筛选初值并回到第一页。
   分页与每页条数可切换，详情可查看，导出使用当前已提交的筛选条件。
5. 处理加载中、空数据和失败状态；保留 0 等有效业务值。
   长订单号、邮箱和标题不能破坏布局，窄屏下筛选区换行，表格可横向滚动。

数据与接入：
- 若项目已有订单页面，优先在现有页面上实现；否则按现有路由和菜单机制接入。
  保留权限约定，不创建重复入口。
- 已有明确的接口与字典时直接复用，核实字段、码值、金额单位和统计口径，
  不从截图猜测后端契约，也不把当前页数据冒充全量统计。
- 暂无可用接口时，使用独立的 mock（模拟）数据完成本次页面演示，
  支持本地筛选、重置、分页、详情和导出；统计与模拟筛选结果保持一致。
  使用虚构订单和用户数据，不照抄截图中的个人信息。
  明确标注演示数据和待接入接口，不能把接口失败静默替换为模拟成功。

先简述页面入口、拟改文件和复用依据，然后直接实现。
保留当前工作区已有改动，不重写项目结构，不修改无关页面或生成规则。
完成后运行项目现有且与改动相关的检查，说明实际执行结果；
给出页面访问方式、已实现交互、复用来源，以及需要人工验收或联调的项目。
```

## 3. 打开页面，人工验收

按 AI 给出的访问方式运行并打开页面。检查命令与启动命令使用当前项目 `package.json` 中实际存在的脚本。

| 验收项 | 预期结果 |
| --- | --- |
| 页面布局 | 筛选、四张统计卡片、表格与分页齐全，整体接近参考图 |
| 查询与重置 | 筛选生效，重新查询回第一页，重置同时恢复输入和列表条件 |
| 统计与数据 | 统计口径和金额单位明确，模拟数据与真实接口模式清楚 |
| 分页、详情与导出 | 操作可用，结果符合已提交条件；未联调能力明确列出 |
| 状态与布局边界 | 加载、空结果、失败有反馈；长文本和窄屏下布局可用 |
| 项目规范 | 复用现有能力，代码遵循规则和审查后的 profile，检查结果真实 |

不符合预期时，将具体差异和复现步骤发给 AI。例如：

```text
订单管理页面在第 2 页修改支付状态并查询后，仍停留在第 2 页。
预期：使用新条件从第 1 页查询，表格和分页显示一致。
请定位本轮改动中的查询与分页状态，遵循现有组件契约修复，并核对查询和重置行为。
```

**完成标志：** 页面已按图片和项目规则生成，你已审查代码并验收相关交互，真实接口的待联调项有明确记录。
