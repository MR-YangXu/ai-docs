# 一键查看失败订单

## 这次要做什么

继续修改订单页面。现在查看失败订单需要选择支付状态再查询，这次增加一个“只看支付失败”按钮，一次点击完成筛选。如果已有这个入口，直接验证其行为。

使用模拟数据时，准备包含成功和失败订单、足够翻到第 2 页的数据，方便观察筛选和分页变化。

## 复制这段提示词

```text:no-line-numbers
在订单管理页面的搜索按钮旁增加“只看支付失败”按钮。
点击后将支付状态设为失败，同步筛选框，保留其他已提交条件，并从第 1 页查询。
复用现有支付状态字典和查询流程，不新增一套筛选逻辑。
点击重置时，所有筛选恢复初始值。完成后运行相关检查。
```

## 操作后应看到什么

| 你来操作 | 应该看到什么 |
| --- | --- |
| 翻到第 2 页，点击“只看支付失败” | 支付状态显示失败，页码回到 1，列表只剩失败订单；没有匹配订单时显示空结果 |
| 提交一个其他筛选条件，再点快捷按钮 | 原条件保留，并同时按支付失败筛选 |
| 点击重置 | 支付状态和其他条件都恢复初始值，列表按初始条件重新查询 |
